# OmairStore Data Analysis Project

## Overview

A data analysis project completed using Microsoft Excel. The project focuses on cleaning, organizing, and analyzing sales data and presenting the results through a dashboard.

## Data

The project uses sales data containing information about:

- Date
- City
- Sales Representative
- Store
- Product
- Cost
- Sales

## Tools

- Microsoft Excel

## Project Work

- Data cleaning and preparation
- Data organization
- Profit and profit margin calculations
- Sales analysis
- Data classification
- KPI calculations
- Dashboard creation

## Project Structure

- Table1 – Original dataset
- Clean – Cleaned and prepared data
- Clac – Calculations and analysis
- Dashboard – Data visualization
